# Data Analysis Projects

A collection of data analysis projects using Python, Pandas and NumPy.

## Projects

- Water Quality Analysis
  - Cleaned and analyzed water safety data using Pandas
  - Dataset: https://www.kaggle.com/...

- Netflix Dataset Analysis
  - Explored Netflix content trends using filtering, groupby and visualization
  - Dataset: https://www.kaggle.com/datasets/shivamb/netflix-shows

- Sleep & Screen Time Analysis
  - Analyzed how screen time and phone usage affects sleep quality and stress
  - Dataset: https://www.kaggle.com/...

- Table Tennis (ITTF) Player Analysis
  - Analyzed international table tennis player data including playing styles, grip and activity status
  - Dataset: https://www.kaggle.com/...
